## Calculation conventions and limitations

Degrees clockwise from true north; apparent altitude includes SunCalc refraction. UTC timestamps. Apparent center altitude >0° defines daylight; this differs from sunrise/sunset upper-limb definitions. Outward-facing half-space plus uniform horizon threshold defines potential direct sun. Five-minute midpoint sampling; approximate boundaries, narrow intervals may be missed. Multiple intervals are retained. No automatic zone lookup or geocoder. Automatic Overture building geometry and height coverage are described in the latest milestone below; terrain and map completeness are unverified. Representative season dates are approximate. Civil days use the explicit IANA zone and DST; users must confirm zones for manual/device coordinates. Engine is independent from UI in `src/solar/engine.ts`.

User rejected manual building measurements. Replaced that UI with automatic Overture global building/part footprint lookup, pinned public PMTiles release 2026-09-23.1. Browser downloads only small HTTP ranges, sequential requests, bounded 24-tile cache, 15-second per-request timeout; no keys, paid services or backend. Location changes cancel obsolete UI results. Tap-to-place and keyboard-accessible 10 m point controls select a ground-level patio; zoom 50–600 m. Recorded numeric heights are used directly, missing heights are hatched and excluded, floors never become invented heights. Source credits and ODbL/source-data links appear in the map; original public tile response fixture retains all source attributes. Building records are never persisted with settings; old measured-wall settings are discarded on load.

src/maps/geometry.ts projects geographic coordinates into local east/north metres with date-line wrap, tests ray/polygon extrusion intersections with even/odd courtyard handling and raised-part minimum heights, and computes the same solar-direction ground shadow projection for SVG. Altitude and azimuth come from the existing solar engine. Open patio exposure/timeline/seasons exclude these mapped blockers; opening mode retains facing-direction potential because window/balcony elevation is unknown. Terrain is level, footprints tile-quantized, roof geometry simplified, coverage is a 600 m square half-width. Distant objects, trees, overhangs and elevated balconies remain unresolved. Buildings with parts are approximate extrusions, not surveyed roof geometry. Missing outlines/height gaps mean results are partial, not verified actual exposure.
